# چندزبانه‌سازی کامل بات (fa/ar/en) — وضعیت و ادامهٔ کار

**این یک کار چندجلسه‌ایه.** این فایل دقیقاً می‌گه چی تموم شده، چی نشده، و
هر AI (Codex، Claude Code، Antigravity) باید دقیقاً چیکار کنه تا بدون
گم‌کردن context یا تکرار کار، ادامه بده. طبق `AI_HANDOFF_PROTOCOL.md`، هر
بار که بخشی از این کار رو جلو بردی، این فایل رو آپدیت کن (چک‌لیست پایین رو
تیک بزن) و یک ورودی در `PROJECT_STATE.md` با تگ `[اسم خودت]` اضافه کن.

---

## ۱) زیرساخت — تمام شد، ۲۰۲۶-۰۹-۲۰ (Claude Code)

- **`src/khatmsaz/i18n/__init__.py`** — رجیستری مرکزی ترجمه. تابع
  `t(key, lang) -> str` و `variants(key) -> frozenset[str]`. بخون
  docstring بالای فایل — همه‌چیز اونجا توضیح داده شده.
- **محدودیت معماری مهم (این رو حتماً بخون قبل از ادامه دادن):**
  فیلترهای aiogram مثل `@router.message(F.text == X)` **قبل از اجرای
  handler** ارزیابی می‌شن، یعنی نمی‌تونن زبان کاربر رو از دیتابیس بخونن.
  پس هر دکمه‌ای که متنش زبان‌محور بشه، دیگه با یک `==` ساده قابل تشخیص
  نیست — باید با `F.text.in_(variants("key"))` چک بشه. برای دکمه‌های منوی
  اصلی این کار انجام شده (`bot/keyboards.py`، دنبال `_BUTTON_TEXTS`
  بگرد). **هر دکمهٔ reply-keyboard جدیدی که زبان‌محور می‌کنی، باید همین
  الگو رو دنبال کنه.** دکمه‌های inline (callback_data) این مشکل رو ندارن،
  چون callback_data خودش زبان‌محور نمی‌شه، فقط متن نمایشی دکمه عوض می‌شه.
- **`UserSettings.language_prompted`** (مایگریشن `c9d0e1f2a3b4`) — فلگ
  جدید که مشخص می‌کنه آیا کاربر تا حالا سؤال زبان رو دیده یا نه (چون
  `language` پیش‌فرضش "fa"ه و نمی‌شه ازش فهمید کاربر واقعاً انتخاب کرده یا
  نه).
- **جریان اول کار با بات (`bot/handlers/start.py`):** الان دقیقاً طبق
  خواستهٔ مالک پروژه کار می‌کنه — پیام خوش‌آمد اول نشون داده می‌شه، بلافاصله
  بعدش سؤال زبان (دکمه‌های فارسی/العربية/English) با callback
  `first_lang:<code>`. انتخاب، `settings_service.set_language` رو صدا
  می‌زنه و منوی اصلی رو با همون زبان نشون می‌ده. کاربرهایی که قبلاً پرسیده
  شدن (`language_prompted=True`) فقط منوی معمولی رو با `settings.language`
  فعلی‌شون می‌بینن — دوباره ازشون پرسیده نمی‌شه.
- **۶ دکمهٔ منوی اصلی کاملاً چندزبانه شدن:** «📅 امروز»، «🕋 ختم‌های من»،
  «📊 گزارش من»، «⚙️ تنظیمات»، «➕ ساخت ختم جدید»، «❓ راهنمای کامل».
  فیلترهای مربوطه در ۶ فایل (`create_khatm.py`, `help.py`, `my_khatms.py`,
  `report.py`, `settings_menu.py`) به `F.text.in_(..._TEXTS)` تبدیل شدن.
- **متن خوش‌آمد (`welcome.text`)** به هر سه زبان کامله.
- با یک تست مستقیم روی Postgres واقعی تأیید شد: `t()`/`variants()` درست
  کار می‌کنن، `main_menu_keyboard(lang)` واقعاً کیبورد رو localize می‌کنه،
  `language_prompted`/`set_language` درست ذخیره و آپدیت می‌شن.

## ۲) چیزی که هنوز چندزبانه نشده (اکثریت قریب‌به‌اتفاق بات)

فقط اسکلت منوی اصلی و پیام خوش‌آمد چندزبانه‌ست. **همهٔ پیام‌های دیگه —
راهنما، ویزارد ساخت ختم، تنظیمات، پیام‌های یادآوری (به‌جز اونایی که از قبل
`message_template` locale-aware داشتن)، پیام‌های مدیریت ختم، پیام‌های
خطا — هنوز فقط فارسی هستن.**

### الگوی دقیق برای تبدیل هر رشتهٔ جدید

1. یک کلید کوتاه انتخاب کن، گروه‌بندی‌شده بر اساس بخش
   (مثال: `"help.topic.join"`, `"create_khatm.ask_niyyat"`).
2. به `_STRINGS` در `src/khatmsaz/i18n/__init__.py` اضافه کن — هر سه زبان.
   هیچ‌وقت `fa` رو حذف نکن (fallback همیشه لازمه).
3. توی handler، به‌جای متن فارسی هاردکد، `t(key, lang)` رو صدا بزن.
4. اگه handler به `lang` کاربر دسترسی نداره (چون هنوز query نکرده)، اول
   `settings = await settings_service.get_or_create(session, user.id)` رو
   بگیر و `settings.language` رو به‌عنوان `lang` پاس بده.
5. اگه این رشته یک دکمهٔ reply-keyboard است که با `F.text == ...` چک
   می‌شه، حتماً از الگوی بخش ۱ (`variants()` + `F.text.in_(...)`) استفاده
   کن — وگرنه بعد از انتخاب زبان غیرفارسی، اون دکمه دیگه کار نمی‌کنه.

      این ۷ فایل به `t(key, lang)` تبدیل شدن. تست شد: `pytest` کامل، اسکریپت
      one-off برای همهٔ کلیدها + import smoke-test هر ۷ فایل، ری‌استارت بات
      و `/health` سالم. (۲۰۲۶-۰۹-۲۰، Claude Code)
- [x] `admin.py` — **تصمیم مالک پروژه (۲۰۲۶-۰۹-۲۰): «همیشه فارسی بمونه
      (توصیه می‌شود)».** یعنی نیازی به ترجمه نداره؛ عمداً دست نخورده باقی
      می‌مونه.
- [x] `suggestions.py` — بخش «پیشنهادات» جدید (کاربر پیشنهاد/گزارش مشکل
      می‌ده، برای ادمین ارسال می‌شه). ۹ کلید `suggestions.*` از همون ابتدا
      چندزبانه ساخته شد. (۲۰۲۶-۰۹-۲۱، Claude Code)

## ۳) پنل وب — بخش «سازنده» (Mini App تلگرام) چندزبانه شد؛ بقیهٔ پنل ادمین هنوز نه

**به‌روزرسانی ۲۰۲۶-۰۹-۲۰/۲۱ (Claude Code):** مالک پروژه روشن کرد که «وب
اپ» جداگانه‌ای وجود نداره — همون محتوایی هست که در Mini App تلگرام باز
می‌شه (`src/khatmsaz/web/templates/creator_*.html`، مسیرهای `_creator`
در `web/app.py`). این بخش کامل چندزبانه شد:
- الگو: `templates.env.globals["t"] = web_t` (یک تابع جدا از `t()` اصلی
  بات، همون منطق `_STRINGS`)، به‌علاوه `WEB_LABEL_KEYS`/`_web_label` برای
  برچسب‌های enum-مانند (وضعیت ختم، نوع محتوا، ...).
- `_creator()` حالا `(user, raw, lang)` برمی‌گردونه — `lang` از
  `settings_service.get_or_create` (زبان واقعی خودِ سازنده، همون که در
  بات تنظیم کرده) خونده می‌شه، نه از querystring/کوکی جدا.
- ۴ تمپلیت (`creator_base`, `creator_dashboard`, `creator_khatm_detail`,
  `creator_login`) کامل به `{{ t('key', lang) }}` تبدیل شدن؛
  `creator_base.html` هم `lang`/`dir` درست HTML رو ست می‌کنه (rtl برای
  fa/ar، ltr برای en).
- تست شد: `pytest` کامل + کل integration روی Postgres واقعی (شامل
  `test_creator_web_integration.py`/`test_creator_pagination_integration.py`
  که بعد از این تغییر یک بار fixture‌شون به‌خاطر یک side effect جدید
  (`UserSettings` ساخته می‌شه) اصلاح شد).

**هنوز چندزبانه نشده:** بقیهٔ `src/khatmsaz/web/templates/*.html` —
یعنی پنل **ادمین** (نه سازنده) که با `/admin_*` کار می‌کنه. طبق تصمیم
مالک دربارهٔ `admin.py` («همیشه فارسی بمونه») و این‌که این تمپلیت‌ها هم
همون کاربر ادمین رو هدف می‌گیرن، این بخش عمداً دست‌نخورده مونده مگه
مالک صریحاً بخواد این‌ها هم چندزبانه بشن.

### نکتهٔ مهم دربارهٔ تست

بعد از هر فایلی که تبدیل کردی:
1. `PYTHONPATH=src python -m pytest -q` رو اجرا کن.
2. یک اسکریپت one-off بساز که `t()` رو با یک کاربر واقعی en/ar در Postgres
   امتحان کنه (مثل تستی که برای زیرساخت نوشته شد — `/tmp/test_i18n.py` در
   تاریخچهٔ این جلسه، اگه هنوز موجوده).
3. بات رو ری‌استارت کن (`start_bot.ps1` رو باز نگه دار، یا اگه دستی اجرا
   می‌کنی، مطمئن شو Postgres محلی روی ۵۵۴۳۳ بالاست — `docs/ai/DEBUGGING.md`).
