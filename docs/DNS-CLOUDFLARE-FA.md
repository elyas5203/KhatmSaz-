# راه‌اندازی DNS دامنهٔ ختم‌ساز در Cloudflare

## نیم‌سرورهای اختصاص‌یافته

طبق پنل Cloudflare برای `khatmsaz.com`، این دو نیم‌سرور باید در پنل ثبت‌کنندهٔ
دامنه جایگزین نیم‌سرورهای فعلی شوند:

```text
elma.ns.cloudflare.com
lynn.ns.cloudflare.com
```

نیم‌سرورهای فعلی ثبت‌کننده در تصویرها `directi1.irandns.com` و
`directi2.irandns.com` هستند؛ پس از ثبت نیم‌سرورهای Cloudflare، فقط دو مورد
Cloudflare را نگه دارید و موارد قبلی را حذف کنید. اگر ثبت‌کننده گزینهٔ DNSSEC
دارد، تا زمان انتقال کامل آن را خاموش نگه دارید.

## ترتیب کار

1. در پنل ثبت‌کننده، بخش DNS یا Nameserver را باز کنید.
2. حالت استفاده از نیم‌سرور اختصاصی را انتخاب کنید.
3. دو نیم‌سرور بالا را وارد و ذخیره کنید.
4. تا فعال‌شدن وضعیت دامنه در Cloudflare صبر کنید؛ این مرحله ممکن است از چند
   دقیقه تا ۲۴ ساعت طول بکشد.
5. پس از Active شدن دامنه، رکوردهای زیرساخت و زیردامنه‌ها را در Cloudflare
   بسازید؛ قبل از آن زیردامنه‌ها را در ثبت‌کننده نسازید.

## رکوردهای لازم بعد از تأیید

مقدار `<VPS_PUBLIC_IP>` باید IP عمومی VPS واقعی باشد و هنوز در پروژه ثبت نشده
است:

```text
@          A       <VPS_PUBLIC_IP>     Proxy: DNS only یا Proxied طبق سرویس
admin      A       <VPS_PUBLIC_IP>     Proxy: Proxied
api        A       <VPS_PUBLIC_IP>     Proxy: Proxied
```

برای Callback پی‌پینگ، آدرس نهایی پروژه این است:

```text
https://khatmsaz.com/payments/payping/callback
```

تا وقتی VPS، reverse proxy و گواهی HTTPS آماده نشده‌اند، این Callback قابل
استفادهٔ واقعی نیست.

## وضعیت فعلی اتصال‌ها

### PayPing

- آداپتر نسخهٔ ۳، ساخت پرداخت، Callback، بررسی مبلغ/فاکتور و جلوگیری از
  replay در کد پیاده‌سازی و تست شده است.
- `PAYPING_API_TOKEN` هنوز خالی است.
- باید فقط API Token اختصاصی از پنل توسعه‌دهندگان پی‌پینگ ساخته شود؛ ساخت
  محصول یا Referral URL برای این اتصال لازم نیست.
- نام کاربری و رمز پنل نباید در پروژه، `.env` یا مستندات ذخیره شوند.
- بعد از آماده‌شدن HTTPS باید یک پرداخت واقعی کم‌مبلغ آزمایشی انجام شود.

### Kavenegar

- آداپتر واقعی Kavenegar و حالت امن `noop` پیاده‌سازی شده‌اند.
- تنظیم فعلی پروژه عمداً غیرفعال است:

```dotenv
SMS_PROVIDER=noop
SMS_API_KEY=
SMS_SENDER=
```

- برای فعال‌سازی واقعی، از پنل کاوه‌نگار API Key و شمارهٔ خط خدماتی تأییدشده
  را بردارید و فقط در `.env` سرور قرار دهید:

```dotenv
SMS_PROVIDER=kavenegar
SMS_API_KEY=<KAVENEGAR_API_KEY>
SMS_SENDER=<APPROVED_SERVICE_SENDER>
```

- شماره‌های خارج از ایران عمداً از Kavenegar عبور نمی‌کنند و طبق منطق پروژه
  یک بار در صف تأیید دستی ادمین قرار می‌گیرند.

## چیزهایی که بعد از تأیید نیم‌سرورها لازم است

- IP عمومی VPS
- نصب reverse proxy و TLS برای `khatmsaz.com`
- ساخت رکوردهای DNS بالا
- قرار دادن API Token پی‌پینگ و در صورت نیاز کلید کاوه‌نگار در `.env` سرور
- اجرای پرداخت کم‌مبلغ و تست ارسال OTP واقعی
