# راهنمای مینی‌اپ مدیریت ختم‌ساز

رابط مدیریت فقط به‌صورت Mini App داخل تلگرام ارائه می‌شود و ورود مستقل
مرورگری یا لینک توکن‌دار ندارد. فقط کاربری که نقش مدیریتی معتبر دارد و
هویت امضاشدهٔ تلگرامش در سرور تأیید شود وارد می‌شود.

## پیش‌نیاز تست با گوشی

تلگرام برای دکمهٔ Mini App یک آدرس عمومی HTTPS می‌خواهد؛ IP محلی و HTTP
برای تست واقعی کافی نیست. پس از فعال‌شدن DNS، مقدار زیر را تنظیم کنید:

```text
ADMIN_WEB_BASE_URL=https://app.khatmsaz.com
```

سپس بات را اجرا کنید و در گفت‌وگوی خصوصی با بات بفرستید:

   ```text
   /admin_app
   ```

دکمهٔ «باز کردن مینی‌اپ مدیریت» را بزنید. سرور امضای Telegram initData و
تازه‌بودن آن را بررسی می‌کند و سپس نشست امن هشت‌ساعته می‌سازد.

بازکردن مستقیم `/login` یا افزودن `?token=...` ورود ایجاد نمی‌کند. گزینهٔ
«خروج امن» نشست را باطل می‌کند.

## امکانات نسخهٔ فعلی

- نمای کلی کاربران، ختم‌های فعال، اعضای فعال و صف‌های در انتظار
- فهرست و جزئیات ختم‌ها همراه آمار و اعضا
- جست‌وجوی کاربر و عملیات هشدار، تعلیق، مسدودسازی و فعال‌سازی مجدد
- مشاهدهٔ تاریخچهٔ قالب‌های پیام و فعال/غیرفعال‌کردن نسخه‌ها
- رابط فارسی راست‌به‌چپ و منوی پایین مخصوص موبایل

تمام درخواست‌های تغییردهنده با CSRF محافظت می‌شوند، کوکی نشست `HttpOnly` است
و پاسخ‌های پنل ذخیرهٔ مرورگر نمی‌شوند. HTTPS و کوکی `Secure` برای Mini App
اجباری‌اند.
